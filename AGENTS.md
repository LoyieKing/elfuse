# Working agreements

- Commit each completed and verified item immediately, before starting the next item. Keep one functional item per commit; do not accumulate completed work.
- Preserve outstanding items in ../umaru/docs/todo.md and docs/fork-scheduling.md. A completed task does not close unrelated backlog items.
- Commit only the relevant source, tests and documentation. Leave unverified work and unrelated user files unstaged.
- Keep original APKs unchanged; fixes belong in elfuse, the owned runtime or AOSP patches.
